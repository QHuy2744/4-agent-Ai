Đội Ngũ 4 AI Agent

Mỗi agent đảm nhận một vai trò chuyên biệt, phối hợp nhịp nhàng như một đội ngũ kỹ sư thực thụ.

Chiến Lược

1. Planner

Kiến trúc sư & Lập kế hoạch

Phân tích yêu cầu gốc, lập kế hoạch chi tiết từng bước, chia nhỏ công việc và xác định các file cần thay đổi trước khi triển khai.

Phân tích Lập kế hoạch Thiết kế hệ thống
Thực Thi

2. Coder

Lập trình viên & Phát triển

Đọc kỹ kế hoạch từ Planner, viết mã nguồn sạch, chính xác, tuân thủ quy ước codebase và bàn giao kết quả hoàn thiện.

HTML/CSS/JS Clean Code Triển khai
Kiểm Định

3. Reviewer

Chuyên gia Kiểm tra Mã nguồn

Đánh giá toàn diện mã nguồn do Coder thực hiện, đảm bảo tuân thủ tiêu chuẩn chất lượng, bảo mật và tính tối ưu.

Code Review Bảo mật Tối ưu hóa
Đảm Bảo Chất Lượng

4. Tester

Kỹ sư Kiểm thử Phần mềm

Kiểm thử giao diện, tính năng, độ tương thích trên các thiết bị và xác nhận sản phẩm đạt chuẩn trước khi phát hành.

UI/UX Testing Responsive Bug Detection
