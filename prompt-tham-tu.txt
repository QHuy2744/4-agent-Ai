TẠO PROJECT: AI THÁM TỬ — DETECTIVE CASE

Mục tiêu:
Xây dựng một game web điều tra/phá án hoàn chỉnh, mobile-first, chạy tốt trên Android và desktop. Người chơi đóng vai thám tử, thu thập manh mối, đọc lời khai, thẩm vấn nghi phạm, dựng timeline và cuối cùng đưa ra kết luận về hung thủ.

QUAN TRỌNG:
- Giữ nguyên kiến trúc 4 AI Agent hiện tại.
- Không thay đổi cơ chế Planner → Coder → Tester → Reviewer.
- Không thay đổi cơ chế Auto-Fix tối đa 3 vòng.
- Không tự động git push.
- Không tự động tạo Pull Request.
- Reviewer phải trả về CHOT trước khi thay đổi được áp dụng.
- Không xóa hoặc phá hỏng các script pipeline hiện tại.
- Không sử dụng API key trực tiếp trong frontend.
- Project phải chạy được mà không cần backend.
- Nếu chưa có backend/API thật, AI phải được mô phỏng bằng logic JavaScript local.
- Ưu tiên hoàn thiện sản phẩm chạy được hơn là tạo code quá phức tạp.
